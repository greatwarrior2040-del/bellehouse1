# bellehouse1

Site multipage Belle House Niger, inspiré de la direction visuelle fournie : navigation fixe, hero animé au scroll, sections éditoriales, réalisations, CTA mobile et chatbot local.

## Prévisualiser

Depuis ce dossier :

```powershell
node .\preview-server.mjs
```

Puis ouvrir http://127.0.0.1:4173/

## Pages

- `belle-house-niger/index.html`, accueil et hero sticky animé au scroll.
- `belle-house-niger/a-propos.html`, approche et engagements.
- `belle-house-niger/services.html`, construction, ferraillage, ingénierie BTP et rénovation.
- `belle-house-niger/realisations.html`, portfolio filtrable.
- `belle-house-niger/contact.html`, contact, appel, WhatsApp et formulaire email.

Les médias de référence portant la marque Briand restent dans `review/` et ne sont pas publiés dans le site Belle House.
